AQUASCAN AI is developed by THRYVEX as an AI-powered solution for analysing Side-Scan Sonar imagery and assisting underwater object and anomaly detection.

ABOUT THE PROJECT

Intelligence beneath the surface.

AQUASCAN AI combines artificial intelligence, computer vision, sonar image processing and web technologies into one integrated platform.

The system is designed to assist users in analysing Side-Scan Sonar imagery, identifying detectable objects, viewing confidence scores and maintaining detection history.

The platform is being developed as a software prototype with scope for future integration with real-world marine sonar systems and specialized underwater datasets.

PROJECT DETAILS

AQUASCAN AI at a glance.

Problem Focus

Automated analysis of Side-Scan Sonar imagery to assist in identifying underwater marine debris and other detectable anomalies.

Input

Side-Scan Sonar images uploaded through the AQUASCAN AI analysis dashboard.

AI Output

Detected object categories, confidence values and approximate object localization through bounding boxes.

Result Management

Analysis results can be stored locally and reviewed through the Detection Reports interface.
